# Nädal 9: Värbamisjuhend (Grupitöö)

Selle nädala töö keskendus andmeanalüütiku portfoolio hindamisele tööandja vaatenurgast ning UrbanStyle'i värbamisjuhendi koostamisele.

- **Roll:** B – tehniline intervjueerija
- **Panus:** Hindasin kaaslase GitHubi portfooliot tehniliste oskuste, koodi struktuuri, dokumentatsiooni ja commit-sõnumite põhjal. Panustasin meeskonna värbamisjuhendisse tehnilise hindamise kriteeriumide ja praktiliste soovitustega.
- **AI kasutamine:** Kasutasin AI-d portfoolio analüüsi struktureerimiseks ning tagasiside selgemaks ja arengut toetavamaks sõnastamiseks. Kontrollisin ja kohandasin soovitused koolituse nõuete ning kaaslase tegeliku töö järgi.
